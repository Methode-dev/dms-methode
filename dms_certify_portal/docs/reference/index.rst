Reference
=========

Symbol-by-symbol documentation of everything the addon defines.

If you are looking for *how to do something* rather than *what something is*, you
want the :doc:`../handbook/index` instead.

How to read these pages
-----------------------

Every symbol carries a **[source]** link to the exact file and line on GitHub. Two
mechanisms produce them, which is why some pages look different from others:

* :doc:`tools/seal` and :doc:`hooks` are plain Python with no Odoo model in them, so
  they are generated by ``autodoc`` straight from the source and its docstrings.
  What you read is what the code says, by construction.
* Everything else is **hand-written**. An Odoo model's fields only exist once a
  registry is built, and Odoo is not installed in the documentation build, so
  ``autodoc`` has nothing to introspect. These pages declare their symbols
  explicitly and still get source links, via ``linkcode``.

Non-Python sources — view XML, the QWeb templates, data XML, the access matrix, SCSS
and JS — are linked with an inline :ghsrc:`__manifest__.py`-style link to the file.

Field entries give the Odoo type, the declaration verbatim, what it is for, and — for
computed fields — what recomputes them and why the dependency list is what it is.

Models
------

The five models this addon defines, and the two it extends.

.. list-table::
   :header-rows: 1
   :widths: 34 24 42

   * - Page
     - Odoo model
     - Role
   * - :doc:`models/dms_certificate`
     - ``dms.certificate``
     - One verifiable document: the registry entry, the seal, the matching
   * - :doc:`models/dms_certificate_holder`
     - ``dms.certificate.holder``
     - A person listed on a document, their keyed hashes and redaction boxes
   * - :doc:`models/dms_certificate_type`
     - ``dms.certificate.type``
     - What kind of document this is — a record, not a selection
   * - :doc:`models/dms_certificate_attempt`
     - ``dms.certificate.attempt``
     - The lookup audit trail, and both rate limits
   * - :doc:`models/ir_http`
     - ``ir.http`` *(extended)*
     - Routing the check host onto the portal, and nothing else
   * - :doc:`models/res_config_settings`
     - ``res.config.settings`` *(extended)*
     - Throttling, portal behaviour, certificate defaults, seal house style
   * - :doc:`tools/seal`
     - *not a model*
     - The stamping itself: bytes in, bytes out, no ORM
